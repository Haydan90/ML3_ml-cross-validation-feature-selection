# Проект ML3: Кросс-валидация, отбор признаков и оптимизация гиперпараметров

В этом проекте исследуются продвинутые методы валидации моделей машинного обучения, различные техники отбора признаков (Feature Selection) и подбора гиперпараметров на датасете аренды квартир.

---

## 1. Теоретические основы и методы

### 1. Кросс-валидация и схемы разбиения
- **Leave-One-Out (LOO):** Частный случай K-Fold, где на каждой итерации в качестве теста используется ровно один объект ($n-1$ для обучения, $1$ для теста), и процедура повторяется $n$ раз. 
  - *Плюсы:* Максимальное использование данных для обучения, отсутствие стохастичности при разбиении.
  - *Минусы:* Крайне высокая вычислительная сложность, не применима для больших датасетов.
- **K-Fold / GroupKFold / StratifiedKFold / TimeSeriesSplit:** Реализованы кастомные аналоги стандартных разбиений из `scikit-learn` для работы с обычными данными, группами (`building_id` / `interest_level`) и временными рядами (`created`).

### 2. Методы отбора признаков (Feature Selection)
Классификация подходов:
1. **Фильтры (Filters):** Оценивают признаки до обучения модели с помощью статистических критериев (корреляция Пирсона, Хи-квадрат, дисперсия).
2. **Встроенные методы (Embedded):** Отбор происходит прямо в процессе обучения модели (например, Lasso-регуляризация, обнуляющая коэффициенты слабых признаков).
3. **Оберточные методы (Wrapper Methods):** Используют качество модели как критерий (например, Recursive Feature Elimination).
4. **Важность на основе моделей (Feature Importance / Permutation / SHAP):** Анализ уже обученной модели (Permutation Importance переставляет значения признаков и смотрит на падение метрики; SHAP оценивает вклад каждого признака на основе теории кооперативных игр).

### 3. Оптимизация гиперпараметров
- **Grid Search:** Полный перебор заданных сеток параметров.
- **Random Search:** Случайный выбор комбинаций параметров из заданных распределений.
- **Bayesian Optimization (Optuna):** Интеллектуальный поиск на основе вероятностных моделей (TPE), определяющий перспективные направления для следующих шагов.

## 2. Что было сделано в проекте

1. **Предобработка данных:** Загрузка датасета `train.json`, маппинг уровня интереса (`interest_level`), очистка и выделение топ-20 бинарных признаков по популярности из поля `features`.
2. **Реализация кастомных сплитеров:** Написаны функции для классического перемешивания, группировки по признакам, стратификации и разделения по временной шкале (`time_series_split`).
3. **Сравнение стратегий кросс-валидации:** Оценка модели `ElasticNet` на различных фолдах с анализом метрики $R^2$.
4. **Отбор и оценка признаков:**
   - Использование коэффициентов `Lasso`-регуляризации для отбора топ-10 признаков.
   - Реализация функции фильтрации по пропускам и мультиколлинеарности.
   - Оценка важности признаков через **Permutation Importance** и **SHAP (SHapley Additive exPlanations)**.
5. **Подбор гиперпараметров:** Сравнение производительности `Grid Search`, `Random Search` и фреймворка `Optuna` для модели `ElasticNet`.

## 3. Результаты экспериментов

В проекте сравнивались модели на основе `Lasso` и `ElasticNet` с разным подходом к отбору признаков и оптимизации гиперпараметров. 

| Модель / Метод отбора | Train (MAE) | Valid (MAE) | Test (MAE) | Test ($R^2$) |
| :--- | :---: | :---: | :---: | :---: |
| **Lasso (MinMaxScaler)** | 966.75 | 1309.12 | 1013.87 | 0.0227 |
| **Lasso (Top-10 по весам)** | 794.20 | 3635.42 | 2770.16 | -15.3115 |
| **Lasso + Feature Selection** | 962.74 | 1300.05 | 1007.78 | 0.0223 |
| **Lasso + Permutation Importance** | 953.09 | 1294.87 | 1001.81 | 0.0224 |
| **SHAP-based Selection** | 1370.12 | 1721.36 | 1424.73 | 0.0025 |
| **Grid Search (ElasticNet)** | 1312.66 | 1666.83 | 1368.42 | 0.0047 |
| **Random Search (ElasticNet)** | 1153.67 | 1504.77 | 1206.51 | 0.0115 |
| **Optuna (ElasticNet)** | 968.87 | 1314.93 | 1018.74 | 0.0219 |

> **Вывод:** Жёсткая фильтрация признаков (например, сокращение до топ-10 по весам Lasso) может приводить к сильному переобучению и падению метрик на валидации/тесте. Наиболее стабильные результаты показали полные наборы признаков с мягким отбором (Permutation Importance, встроенные фильтры) и стандартная масштабированная модель.
